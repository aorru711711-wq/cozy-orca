# Provider icons

Small SVG marks for the agents Cozy Orca can follow: **Orca**, **Claude**, **Codex**, **Antigravity**, and **Pi**.

Each file is drawn for **12–14px** UI use (`width`/`height` default to 14). Icons use `fill="currentColor"` so they inherit the surrounding text color.

| File | Agent |
| --- | --- |
| `orca.svg` | Orca |
| `claude.svg` | Claude (Anthropic) |
| `codex.svg` | Codex (OpenAI) |
| `antigravity.svg` | Antigravity / `agy` (Google) |
| `pi.svg` | Pi |
